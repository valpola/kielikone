        Instructions
        

          

            Type your answer (optional), press Enter or click the "Show Answer" button to reveal, then
            Enter again to auto-grade. You can also grade manually with the buttons.
          

          

            The login button shows who you are when result logging is enabled. Results are
            stored only if you log in with a valid API key.

Filtering

          

            A word is quizzed only if it has every Include tag and
            none of the Exclude tags. So ticking two units asks for words
            belonging to both, which is usually nothing. Ticked tags are listed first, under
            "Selected", and the number beside each tag is how many words carry it.
            The filter applies immediately to the quiz.
          

          
Special "Practice set" tag

          

            "Recompute practice set" picks the words worth practising next, based on your past
            performance, and tags them "Practice set". The set is worked out on this device
            and stored here, so it never travels with the vocabulary and never affects your
            other devices. "Words per practice set" controls how many are picked.
          

          
Session target

          

            "Correct to finish" controls how many correct answers are required before a
            word is skipped for the rest of the session. The correct answers are reset when
            the practice set is recomputed or when the page is reloaded.
