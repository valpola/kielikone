# Grammar Topics by Unit

Index of grammar concepts introduced in each unit of the Turkishle courses,
compiled from the coursebook PDFs. Intended as the map for future grammar-practice
workflows (e.g. an in-repo agentic exercise generator that combines vocabulary the
learner already knows with a target grammar concept, with AI grading of translations).

Entries marked **⊕ GAP** are *not* taught by Turkishle. They come from the learner,
who met them in a prior commercial course and flagged them as worth knowing. Each is
filed under the Turkishle unit where it would naturally belong, roughly matching where
that other course introduced it. Verified absent across all 27 coursebook PDFs, the
3582 cached web-lesson prose blocks and the 1120 vocabulary cards — so "absent" means
absent from the material, though anything taught only in a Turkishle grammar *video*
would not show up in that check.

## A1

### Unit 1 — Tanışma (Introduction)

**1A — Greetings, Introductions & Wishes**
- Greetings: `Merhaba` / `Selam`; time-of-day (`Günaydın`, `İyi günler`, `İyi akşamlar`, `İyi geceler`)
- Welcoming: `Hoş geldin` → response `Hoş buldum`
- Goodbyes: `Görüşürüz` / `Güle güle` / `Hoşça kal` / `Görüşmek üzere`; formal plural `-ın` (`hoşça kalın`)
- "How are you?": `Nasılsın?` / `Nasılsınız?` + responses (`İyiyim`, `Harikayım`, `Yorgunum`…); informal `Naber?` / `Ne var ne yok?` / `Nasıl gidiyor?`
- Introducing yourself: `Ben` + name / `Benim adım` + name
- Asking a name: `Adın ne?` / `İsmin ne?` (formal `Adınız ne?`)
- Asking origin: `Nerelisin?` + nationality suffix **`-lI`** (`Almanyalı`, `İsviçreli`, `Belçikalı`)
- Good wishes (İyi Dilekler): `Geçmiş olsun`, `Özür dilerim`, `Tebrikler`, `Afiyet olsun`, `Çok yaşa`, `İyi yolculuklar`

**1B — Demonstratives, Plurals & the Question Particle**
- Demonstrative pronouns: **`Bu` / `Şu` / `O`** (this / that, chosen by distance); plurals `Bunlar` / `Şunlar` / `Onlar`
- Question words: **`Ne`** (what), **`Kim`** (who)
- Plural suffix **`-lAr`** with **2-way vowel harmony** (`-lar` / `-ler`)
- **4-way vowel harmony** (`ı` / `i` / `u` / `ü`)
- Yes/no question particle **`mI?`** (`mı` / `mi` / `mu` / `mü`); answering with `Evet` / `Hayır, … değil`

### Unit 2 — Nerede? / Kaç? / Sen Kimsin? (Where? / How many? / Who are you?)

**2A — Locative Case & Var/Yok**
- Locative case suffix **`-DA`** (`-da`/`-de`/`-ta`/`-te`); `Nerede?` (where?), `Kimde?` (who has?)
- **`Var` / `Yok`** (there is/are — there isn't/aren't); questions `… var mı?` / `… yok mu?`
- `Ne var?` / `Neler var?` / `Kim var?` / `Kimler var?`

**2B — Numbers**
- Cardinal numbers (`Sayılar`) and how they combine (`On iki`, `Üç yüz yirmi`, `Bin`…)
- **`Kaç?`** (how many? / how much?); age (`Kaç yaşındasın?`), phone numbers, price (`ne kadar?`, `kaç para?`)
- Telling time: `Saat kaç?` → `Saat üç`; **`Kaçta?`** (at what time?)
- Ordinal numbers (`Sıra Sayıları`)

**2C — Nominal Sentences**
- Personal suffixes ("to be"): **`-ım/-sın/-Ø/-ız/-sınız/-lAr`** (`avukatım`, `öğretmensin`…)
- Consonant softening in the suffix ("Ketçap/KTÇP" rule: `genç → gencim`, `kasap → kasabım`)
- Negation with **`değil`** + personal endings (`avukat değilim`…)

### Unit 3 — Nasıl Gidiyor? / Nereden Nereye / Alabilir miyiz? (How's it going? / From where to where / May we?)

**3A — Present Continuous Tense**
- **`-Iyor`** (`-ıyor`/`-iyor`/`-uyor`/`-üyor`) + 4-way vowel harmony; buffer **`-y`** after vowel-final stems (`uyu → uyuyor`, `oku → okuyor`)
- Uses: actions in progress + habits/routines (`her gün` …)

**3B — Dative & Ablative Cases**
- Dative **`-(y)A`** (to / towards): `masaya`, `İstanbul'a`; pronouns `bana/sana/ona/bize/size/onlara`
- Ablative **`-DAn`** (from): `evden`, `İstanbul'dan`
- Case-governed verbs (dative: `bakmak`, `binmek`, `inanmak`, `güvenmek`, `kızmak`…); question forms `Neye? / Kime? / Nereye?`

**3C — Want / Request / Permission**
- Want to: **`-mAk istemek`** (`gelmek istiyorum`)
- Ability/permission/request: **`-(y)AbilmEk`** → `-(y)Abilir miyim?` (may I…?) / `-(y)Abilir misin(iz)?` (could you…?), + `lütfen`

### Unit 4 — Sahibim / Kendi-Hep / Belirtme (Possessives / Self-All / Accusative)

**4A — Possessives (İyelik)**
- Genitive **`-(n)In`** + possessive suffixes: `benim …-(I)m`, `senin …-(I)n`, `onun …-(s)I`, `bizim …-(I)mIz`, `sizin …-(I)nIz`, `onların …-lArI`
- Buffer **`-n-`** before case suffixes on 3rd-person possessives (`evi → evinde`)
- Vowel-drop / softening in stems (`omuz→omzu`, `fikir→fikri`, `renk→rengi`)

**4B — Reflexive `kendi`, `hep(si)`, Countries/Nationalities/Languages**
- Reflexive pronoun **`kendi`** + possessive/case (`kendim`, `kendime`, `kendi kendime`…)
- **`hep` → `hepsi`** (all of it/them) + possessive/case
- Countries / Nationalities / Languages: nationality **`-lI`** (`Almanyalı`), language **`-CA`** (`Türkçe`, `Fransızca`)

**4C — Accusative Case `-(y)I` (Belirtme Durumu)**
- Marks the **definite** direct object (`kitap alıyorum` vs `kitabı alıyorum`)
- Required for: proper nouns, demonstratives + `hangi`/`bütün`/`bazı`, pronouns, and possessive-suffixed objects

### Unit 5 — Türkçe'yi Beş Geçiyor (Telling time / Before-After / Since-For)

**5A — Telling Time (Saatler)**
- Whole hours (`Saat sekiz`), **`buçuk`** (half past), **`çeyrek geçiyor` / `çeyrek var`** (quarter past / to), `(dakika) geçiyor / var` (minutes past/to)
- Past = accusative on the hour (`sekizi çeyrek geçiyor`); To = dative on the hour (`sekize çeyrek var`)
- "at X o'clock" = locative **`-DA`** (`sekizde`); time-of-day words `sabah/öğle/öğleden sonra/akşam/gece`
- **`-DAn -(y)A kadar`** (from … to/until)

**5B — Before & After**
- **`-mAdAn önce`** (before doing X); **`-DIktAn sonra`** (after doing X)

**5C — Since & For**
- **`-DAn beri`** (since a point in time); **`-DIr`** (for a duration) — `geçen yıldan beri`, `sekiz yıldır`

**⊕ GAP — the clitic `dE` (also / too / and)**
- Written **separately** from its host word and only ever `de` / `da` — never `te`/`ta`. That is
  the giveaway distinguishing it from the locative `-DA`, which *is* suffixed and *does* harden:
  `evde` (at home) vs `ev de` (the house too).
- **Position carries the meaning**: it follows whatever it adds to. `Ben de su istiyorum` = *I*
  too want water; `Su da istiyorum` = I want water *too*.
- Turkishle glosses it once in passing in A1 ("Remember: 'de' gives the meaning of 'also'", in
  the `Naber?` dialogue) and teaches it only inside `hem … hem de` (A2-4C). The standalone
  clitic, its placement, and the contrast with the locative are never covered.

### Unit 6 — Şehir & Konum (City & Location)

**6A — Compound Nouns (Ad Tamlamaları)**
- Two nouns combine into one; the parts are **`tamlayan`** (determiner) + **`tamlanan`** (determined).
- **Definite** (Belirtili): tamlayan takes **genitive `-(n)In`**, tamlanan takes **3rd-person possessive `-(s)I`** → `evin çatısı` (the roof of the house), `telefonun ekranı` (the phone's screen). Marks a specific belonging.
- **Indefinite** (Belirtisiz): tamlayan stays **bare** (no genitive), tamlanan takes possessive **`-(s)I`** → `otobüs durağı` (bus stop), `çay bardağı` (tea glass) — a generic type, not a specific owner.
- Genitive `-ın/-in/-un/-ün` (`-nın/-nin/-nun/-nün` after a vowel); possessive `-ı/-i/-u/-ü` (`-sı/-si/-su/-sü` after a vowel).

**6B — The `-ki` Suffix**
- **Adjective function (Sıfat -ki):** attaches after the **locative `-DA`** or a time adverb, turning the word into an adjective ≈ relative "who/which/that" → `odadaki adam` (the man in the room), `sonraki otobüs` (the next bus). Vowel harmony applies only to `dün → dünkü` and `gün → bugünkü`; otherwise `-ki` is invariant.
- **Pronoun function (İlgi zamiri -ki):** attaches to a **genitive** to mean "the one that / that of" → `kedininki` (the cat's one), `arka odanınki` (the back room's); possessive pronouns `benimki` (mine), `seninki` (yours), `onunki` (his/hers).

**6C — Comparatives & Superlatives (Karşılaştırmalar & Üstünlük)**
- Comparative: **`-DAn daha + adjective`** ("more … than"); `daha` is optional (`Asya'dan (daha) güzel`). Ablative harmony `-dan/-den`, `-tan/-ten` after sharp consonants (f,s,t,k,ç,ş,h,p).
- **Less:** `daha az + adjective` (`daha az zeki` = less intelligent); colloquially Turks prefer `… -DAn … değil` ("not more … than").
- Superlative: **`en + adjective`** (`en büyük` = biggest, `en yakın` = nearest).

## A2

### Unit 1 — Emir, İstek & Yapım Ekleri (Imperative, Optative & Derivational Suffixes)

**1A — Imperative Mood (Emir Kipi)**
- No 1st-person forms (you can't command yourself), so **ben/biz have no suffix**. `sen` = bare stem (`kal`, `doğra`); negative just **`-mA`** (`kalma`, `gelme`).
- `o`: **`-sIn`** (4-way), neg **`-mAsIn`**; `onlar`: `-sIn(lar)`. `siz`: **`-In / -InIz`** (longer = more formal), neg **`-mAyIn / -mAyInIz`** (`Sigara içmeyiniz!`).
- Four functions: order, warning, request (`rica`), permission. 3rd-person question `-sIn mI?` = permission/wish (`Öğrenciler girsin mi?`).

**1B — Optative Mood (İstek Kipi)**
- Only 1st person: `ben` **`-(y)AyIm`** (neg `-mAyAyIm`), `biz` **`-(y)AlIm`** (neg `-mAyAlIm`); buffer `y` after vowel stems (`arayayım`).
- "Let's…"; the question form = "Shall we…? / Would you like to…?" (`Kek yapalım mı?`). Colloquial vowel-narrowing (`geleyim`→*geliim*) but spelling kept.

**1C — Noun & Adjective-making Suffixes (İsim & Sıfat Yapan Ekler)**
- **`-lI`** (with/having; 4-way): qualities (`hızlı`), origin (`İstanbullu`), flavour/material (`çilekli`, `tavuklu`), weather (`yağmurlu`), people (`mavi gözlü`, `uzun boylu`).
- **`-sIz`** (-less/without): `şekersiz` (sugarless), `başarısız`, `sensiz`.
- **`-lIk`** (noun-maker): abstractions (`gençlik`, `güzellik`), tools (`gözlük`, `kulaklık`), places (`çöplük`), professions (`öğretmenlik`), allocation (`kışlık`, `aylık`, `dört kişilik`).

**⊕ GAP — intensifying adjectives by syllable reduplication (pekiştirme)**
- The first syllable is repeated with a consonant inserted, intensifying the adjective —
  most visibly with colours: `mavi → masmavi` (deep blue), `kırmızı → kıpkırmızı` (bright red),
  `beyaz → bembeyaz`, `yeşil → yemyeşil`, `siyah → simsiyah`, `sarı → sapsarı`.
- **The inserted consonant is not predictable** (`m`, `p`, `r`, `s` depending on the word), so
  these are learned per item rather than derived — which makes them deck material, not a rule.

### Unit 2 — Geçmiş Zaman & İle (Past Tense & "with/and")

**2A — Definite/Witnessed Past `-DI` (Görülen Geçmiş Zaman)**
- **`-DI`** (4-way) for personally-witnessed, certain, completed past; hardens to **`-tI`** after sharp consonants (f,s,t,k,ç,ş,h,p). Endings `-m/-n/-∅/-k/-nIz/-lAr` (`geldim`). Neg `-mA + -DI` (`gitmedi`); question separate `mI` (`Geldin mi?`).

**2B — Past in Nominal Sentences & Conjunctions**
- Copular past **`-(y)DI`** ("was/were") on nouns/adj: `-ydI` after vowel, `-tI` after sharp consonant (`açtım` = I was hungry). Neg **`değil + -DI`** (`aç değildim`); question `mI + -(y)DI` (`aç mıydım?`); `onlar` → `-lArdI`.
- Cause–effect conjunctions: **`çünkü`** (because), **`bu nedenle / bu sebeple`**, **`bu yüzden`** (that's why), **`dolayısıyla`** (thus).

**2C — `ile` (With & And)**
- `ile`, or clitic **`-lA`** (`-la/-le`), **`-ylA`** after vowel; proper nouns take apostrophe (`Burak'la`).
- **Conjunction** "and" (`elmayla çilek`); **instrumental**: instrument (`bıçakla`), togetherness (`abimle`), by/via (`uçakla`), manner (`öfkeyle`). Question words `neyle?`, `kimle?`.

### Unit 3 — Gelecek Zaman & Karşılaştırmalar (Future & Comparisons)

**3A — Future Tense (Gelecek Zaman)**
- **`-(y)AcAk`** (2-way `-acak/-ecek`) "will/going to"; buffer `y` after vowel (`okuyacak`). Final `k → ğ` before ben/biz endings (`geleceğim`, `alacağız`). Neg `-mA + -yAcAk` (`gelmeyecek`); question `Gelecek misin?`.

**3B — Future with "Olacak"**
- **`olacak`** ("will be"): Noun/Adj + `olacak` + ending (`Hayat güzel olacak`). Same `k → ğ` (`olacağım`, `olacağız`). Neg `olmayacağım`; question `olacak mı?`.

**3C — Comparisons: Kadar & Gibi (Karşılaştırmalar)**
- **`kadar`** ("as … as"): `noun + kadar + adj` (`Ahmet, Onur kadar uzun`); negate with `değil`. Pronouns take possessive: `benim kadar`, `onun kadar`.
- **`gibi`** ("like/as", resemblance): `noun + gibi` (`senin gibi inatçı`). *(A2-3 teaches comparison via `kadar`/`gibi` — not `daha`/`en`, which are the A1-6 forms.)*

### Unit 4 — Belirsiz Geçmiş Zaman & Aktarım (Reported Past & Speech)

**4A — Reported/Inferential Past `-mIş` (Belirsiz Geçmiş Zaman)**
- **`-mIş`** (4-way) + ending; neg `-mA + -mIş` (`gelmemişim`); question separate `mI` (`Gelmiş miyim?`).
- Two functions: **hearsay** (unwitnessed — `Funda İspanya'ya taşınmış`) and **sudden self-realization** (`Anahtarımı evde bırakmışım!`). 3pl `-lAr` optional. Pairs with past adverbs (`dün`, `geçen hafta`).

**4B — `-mIş` in Nominal Sentences**
- **`-(y)mIş`** on nouns/adj (`güzelmiş`; `mutluymuş` after vowel). Neg **`değil + -mIş`** (`evde değilmiş`); question `güzel miymiş?`. Often best in English present (ongoing state just realized): `Bu kitap çok güzelmiş`.

**4C — Direct Speech & Correlative Conjunctions (Dolaysız Anlatım & Bağıntılı Bağlaçlar)**
- Direct speech via **`demek`** conjugated (`diyor / der / dedi / demiş` — tense signals witnessed vs. hearsay); **`diye`** (`demek` + dative) subordinates a quote before saying/thinking verbs (`diye sordu`, `diye düşündü`).
- Correlatives: **`hem … hem (de)`** (both…and), **`ne … ne (de)`** (neither…nor — *affirmative* verb, negative meaning), **`ya … ya (da)`** (either…or). `ne … ne` between opposite adjectives = an in-between state (`ne sıcak ne soğuk`).

**⊕ GAP — vagueness markers: `falan` / `filan` and m-reduplication**
- **`falan` / `filan`** after a word = "and so on / and such": `Salata falan yapıyorum` (I'm
  making salad and so on). Both together, `falan filan`, is very common in speech.
- **m-reduplication**: repeat the word with initial `m` to the same effect — `Ekmek mekmek
  alacağım` (I'll buy bread and such), `Film milm izledik`. If the word already starts with `m`,
  this is impossible and `falan`/`filan` is used instead.
- Turkishle never explains either, yet *uses* `falan` unglossed in a B1.1 dialogue
  (`elbise, şort falan alamadım`) — so the learner meets it without being taught it.

### Unit 5 — Geniş Zaman & `-DIr` (Aorist & the `-DIr` Suffix)

**5A — Aorist / Simple Present (Geniş Zaman)**
- Semi-irregular **`-Ir / -Ar`** (memorize): polysyllabic → 4-way `-Ir` (`kullanır`), monosyllabic → mostly 2-way `-Ar` (`güler`, `yazar`), vowel-final → `-r` (`arar`, `okur`). Irregular monosyllables take `-Ir` (`alır, gelir, verir, bilir, olur, görür`…).
- Negative **`-mAz`**, but Ben/Biz drop `-z` → bare `-mA` (`almam`, `almayız`); question `Gelir miyim?`, neg question `almaz mıyım?`.

**5B — Aorist Questions & Functions**
- Uses: facts/laws (`Su 100 derecede kaynar`), habits (`Her sabah kahve içerim`), likes/dislikes, guesses (`Bence Can kazanır`), **polite requests** (`Tuzu uzatır mısın?`), probability (`Belki sahile gideriz`).

**5C — The `-DIr` Suffix**
- **`-DIr`** = fact or guess; 4-way + assimilation (`-tIr` after sharp consonants). On nouns/adj (`güzeldir`, `yoldadır`). On verbs: `-Iyordur` (guess only — `uyuyordur`), `-mIştIr` (fact/guess — `kurmuştur` / `unutmuştur`), `-AcAktIr` (mostly guess). Nuance: `uyumuştur` (probably fell asleep) vs `uyuyordur` (probably still sleeping).

### Unit 6 — Yeterlik & Zarf Fiiller (Ability & Verbal Adverbs)

**6A — Ability Suffix `-(y)Abil`**
- **`-(y)Abil`** ("can"; `-abil/-ebil`, buffer `y` after vowel), tense+person attach after (`gelebilirim`, `gelebiliyorum`, `gelebileceğim`, `gelebildim`).
- **Negative drops `-bil`, keeps `-A`** → **`-AmA`** ("cannot"): `yapamam` (Ben/Biz drop `-z`), `yapamazsın`, `yapamıyorum`, `yapamadım`.

**6B — Functions of the Ability Suffix (Yeterlik Fonksiyonları)**
- **Ability** (`Gitar çalabilirim`); **permission** (aorist — `Tuvalete gidebilir miyim?`); **possibility** (`Beşiktaş kazanabilir`).
- Possibility-negative **`-mAyAbil`** ("may not", ~50%) ≠ `-AmA` ("cannot", ~99%): `gelemem` vs `gelmeyebilirim`. Combined **`-AmAyAbil`** = "may not be able to". Also suggestions/polite requests (`İki çay alabilir miyiz?`).

**6C — Verbal Adverbs `-Ip` & `-mAdAn` (Zarf Fiiller)**
- **`-Ip`** links consecutive actions of the *same subject*; tense+person go on the *second* verb only (`Işıkları kapatıp uyudum` = I turned off the lights and slept).
- **`-mAdAn`** ("without / before …ing"; 2-way `-madan/-meden`): `Ceketini almadan çıktı` (left without taking his jacket), `Kahvaltı etmeden güne başlamam`.

## B1.1

*(The B1.1 coursebook is organized into modules, not lettered units.)*

### Module 1 — Past Continuous & Ability Past (Şimdiki Zamanın Hikâyesi)
- **`-Iyordu`** (was/were doing) = `-Iyor` + `-(y)DI`; 4-way harmony — `Dün akşam ders çalışıyordum` (I was studying yesterday evening). Also habitual "used to": `Eskiden muhasebede çalışıyordum`.
- Negative narrows the `-mA` vowel before `-Iyor` (`gelme + iyordu → gelmiyordu`); question `gidiyor muydu?`.
- Ability past **`-Abiliyordu`** (`-Abil` + `-Iyordu`): `yüzebiliyordum` (I could swim); negative `-Amıyordu` (`koşamıyordum`).
- Converb **`-DIğIndA`** (when): possessive-marked, hardens to `-tIğIndA` after f,s,t,k,ç,ş,h,p — `Beni aradığında uyuyordum` (I was sleeping when you called).
- Converb **`-(y)ken`** (while / when): on the aorist for verbs (`sen yemek yaparken` = while you were cooking) and on nouns/adjectives (`küçükken`, `gençken`).

### Module 2 — Aorist Past & Participles (Geniş Zamanın Hikâyesi)
- **`-Ir/-ArdI`** (used to / would): aorist + `-(y)DI` — `Gençken her sabah spor yapardım`. Also hypothetical/polite (`isterdim` = I'd love to).
- Negative uses the aorist negative **`-mAz + dI`** (`yalan söylemezdi` = never used to lie); question `yapar mıydınız?`.
- Participle (Sıfat Fiil) **subject `-(y)An`**: `koşan çocuk` (the running boy); noun can drop (`Bu resimleri yapan kim?`).
- Participle **object/past `-DIK` + possessive`** (`-tIK` after sharp consonants; k→ğ): `hocanın verdiği makale` (the article the teacher gave), `gezdiğimiz müze`.
- Participle **future `-(y)AcAK` + possessive`** (k→ğ): `yarın yapacağım sunum` (the presentation I'll give tomorrow).
- Converb **`-Ir … -mAz`** (as soon as): affirmative + negative aorist of the same verb — `seni görür görmez` (as soon as I saw you).

### Module 3 — Wish & Conditionals (Dilek & Şart)
- Irrealis wish **`-sA`** (often with `keşke`): `Keşke zengin olsak!`; if-clause + aorist main clause `Türkçe bilsem, Türkiye'de yaşarım`.
- **`-sAydI`** (`-sA` + `-DI`): stronger impossibility / past regret — `Keşke dün dondurma yemeseydik`; pairs with `-ArdI` (`Zengin olsaydık Ferrari alırdık`).
- Wish + imperative **`-sAnA / -sAnIzA`** (request/suggestion): `buraya gelsene!`.
- Realis conditional **`-(y)sA`** with tense: aorist `-IrsA` (`gelirse`), present `-Iyorsa`, future `-(y)AcAksA`; also "when" (`Eve gelirsen mesaj at`).
- Nominal/existential: `doluysa`, `değilse`, **`varsa` / `yoksa`** (`Paran varsa…`). Frozen forms: `yoksa` (otherwise), `öyleyse` (in that case), `neyse` (anyway), `oysa` (whereas).

### Module 4 — Future-in-Past & Necessity (Gelecek Zamanın Hikâyesi & Gereklilik)
- **`-(y)AcAktI`** (was going to): intended actions that didn't happen — `Formu dolduracaktı ama tarihi kaçırdı`. Near-miss with `az kalsın/neredeyse` (`Neredeyse treni kaçıracaktım`).
- Necessity **`-mAlI`** (should/must) + personal endings (`gitmelisin`); negative `-mAmAlI`.
- Past necessity **`-mAlIydI`** = "should have" (`ders çalışmalıydın`); inferential **`olmalı`** (must be) — `Büşra olmalı`, `kaçırmış olmalı`.

### Module 5 — Verbal Nouns (İsim-Fiil `-mAK` / `-mA`)
- Infinitive **`-mAk`**: subject/object like "to…/-ing" (`Türkçe öğrenmek…`, `Çimlere basmak yasaktır`). Takes cases (k drops): `-mAktA` (good at), `-mAktAn` (hate …ing), `-mAyA` (dative), `-mAyI` (accusative).
- Verbal noun **`-mA` + possessive** (gerund "his reading"): `Onun okuması çok yavaş`; heads noun clauses whose case is set by the governing verb — `benim gelmemi istiyorsan`, `bağırmalarından bıktım`.

## ⊕ Not covered by either course

Verb-deriving voice suffixes are absent from Turkishle A1–B1.1 *and* from the prior course, so
nothing in the learner's material teaches them. They are grouped here rather than under a unit
because there is no unit that introduces them.

- **Passive `-Il` / `-In`** — `yapmak` (to do) → `yapılmak` (to be done); after `l` or a vowel
  the form is `-In` (`bilmek → bilinmek`, `okumak → okunmak`).
- **Causative `-DIr` / `-t` / `-Ir`** — `ölmek` (to die) → `öldürmek` (to kill), `temizlemek` →
  `temizletmek` (to have cleaned), `içmek` → `içirmek` (to make drink). Note this `-DIr` is a
  *different* suffix from the evidential `-DIr` in A2-5C.

Worth prioritising for two reasons. First, the learner's stated preference is to meet
derivational suffixes early, since they govern how a known root can actually be used. Second,
the deck already depends on this: the transitivity tips (`to spread (transitive)`) exist so that
the counterpart can be *derived* rather than carded separately — the intransitive of a
transitive verb via `-Il`/`-In`, the transitive of an intransitive one via the causative. That
payoff only lands once the derivation itself is known.

Turkish voice morphology is close enough to Finnish (`-ttaa`/`-ttää` causatives, passive) that
these may be quick wins rather than heavy grammar.
